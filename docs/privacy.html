Privacy

The data used by a task depends on the model, tools and connected services you choose. Agreement to the terms above is not blanket consent to access or disclose personal information. Any consent required by law or the distribution platform must still be obtained for the relevant feature.

Data on your computer

The app stores conversations, project memory, settings, logs and credentials in its local data folder. Agents can read project files, write changes and run commands as part of the tasks you give them. Use the app with projects you intend it to access and review the resulting changes and activity.

Portable installs normally keep data next to the app. Microsoft Store installs use the package's per-user LocalState folder. A configured data-directory override can change that location. Local files are subject to your Windows account's access controls and any backup or sync software you use.

Models and online tools

Local inference can process prompts on your machine using the built-in model engine or a local model provider such as Ollama. Model downloads contact the hosting service. Choosing a hosted provider sends prompts, conversation context and relevant project or tool content to that provider. Its terms, privacy practices and charges apply.

Web searches, browsing, remote tools and other network features contact their destinations and send the inputs needed for that operation. A local model does not make network tools offline. Connected providers and websites may receive network information such as your IP address.

Optional Cloudflare connections

Connecting Cloudflare authorizes the features you use in your own account. These may include Workers AI, Workers, R2 storage, Containers and Tunnel. Workers AI receives model requests. R2 backup can upload conversations and related app data; automatic backup is enabled by default for a connected account and can be turned off in the app. Cloud tasks upload their task inputs and runtime to your account and may continue while the desktop app is closed. Cloudflare's terms and privacy practices apply.

Updates and distribution

Official portable bundles check GitHub for app releases. Microsoft Store manages updates for Store installations. Those services handle downloads and associated network requests under their own privacy policies.

Removing data and disconnecting services

You can remove conversations and other local data using available app controls, or close the app and remove its data folder. Back up anything you wish to keep. Removing the app or local data does not remove copies held by a hosted provider, your own backups or resources deployed into a cloud account. Manage those copies and revoke connected-service access with the relevant provider. Previously deployed cloud tasks and resources may need to be stopped or deleted separately.
