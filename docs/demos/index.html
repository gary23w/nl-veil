Know what you are running.

SignalDesk is a local prototype with synthetic data. Browser storage is not a production database. Real service deployment needs authentication, authorization, server persistence and further testing.

Cloudflare AI requires an account and internet access and processes prompts remotely. Check model pricing. Coding tools need Python; some checks need Node. Local model weights are a separate download.

Release binaries are unsigned. Follow your operating system's approval flow only for releases you trust.
