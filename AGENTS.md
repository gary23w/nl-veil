# Agents

Working on this tree with an AI tool? `CLAUDE.md` is the working agreement — build oracle, hard
rules, component map — and `harness/TESTING.md` is the house test pattern. Read those two, whatever
the tool.

Scope is whatever the owner asked for. This repo has no self-improvement loop and no standing
backlog for an agent to mine: nothing here points the engine at its own source, and no automated
process may edit the oracle (`scripts/check.*`), `.github/workflows/`, the test roots, or these
instructions. One reviewed change at a time.
